# Accessibility Checklist (WCAG 2.1 AA)

- Keyboard navigation: All interactive controls reachable and operable.
- Focus management: Visible focus indicators; logical tab order.
- Semantics: Proper landmark roles and headings (if UI present).
- Forms: Labels, error messaging, and instructions are programmatically associated.
- Contrast: Text and UI components meet contrast ratios.
- Media: Provide text alternatives for non-text content.
- Status messages: Announced to assistive tech without focus loss.
- Timing: No unexpected timeouts or provide mechanisms to extend.
- Language: Page language set; changes identified.
- Responsive: Content reflows without loss of information.
